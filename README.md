# 3Dプリンター原価・販売価格計算ツール（品質改善版）

## 変更点
- 提案販売価格と損益分岐価格を1円単位で切り上げ、目標利益率を丸めで下回りにくくしました。
- 計算例と、入力を変えたときに期待する挙動の説明を追加しました。
- 失敗率の計算前提をより明確にしました。
- 結果の注意書きを改善しました。

## 手動テスト項目
1. 初期値でフィラメント代が200円になること。
2. 初期値で電気代が23円（四捨五入表示）になること。
3. フィラメント価格を上げると原価と提案価格が上がること。
4. 目標利益率を上げると提案価格が上がること。
5. 販売手数料率を上げると提案価格が上がること。
6. 梱包費または送料を上げると原価と提案価格が上がること。
7. 失敗率を上げると失敗率込みの製造原価が上がること。
8. スプール重量を0にすると入力エラーが表示されること。
9. 販売手数料率と目標利益率の合計が100%以上なら計算不可の警告が表示されること。
10. 目標販売価格が整数円で切り上げ表示されること。

## 注意
このツールは概算用です。人件費、税金、固定出品料、保守費、返品・値引き、材料ロス等は別途考慮してください。
